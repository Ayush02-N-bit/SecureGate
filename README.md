# SecureGate

Smart society security and management application.

## Features
- Visitor management
- Resident signup/login
- Complaint tracking
- Firebase integration
- Admin and guard workflows

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Configure Firebase credentials locally.
4. Run `node server.js`.

## Security
Sensitive Firebase service-account credentials are intentionally excluded from this repository. Do not commit `serviceAccountKey.json` or other secrets.
